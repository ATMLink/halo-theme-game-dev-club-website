# halo-theme-zjutdev

面向“创游工坊 / ZJUT Dev”的 Halo 2 自定义主题。主题只负责前台展示，登录、上传、发布文章和图片管理继续使用 Halo 原生后台。
纯vibe coding

## 适配版本

- Halo 2.15.0 及以上
- 无前端构建步骤，直接打包主题目录即可上传

## 已完成的 MVP

- 首页：Hero、社团介绍摘要、首页轮播、作品卡片区、最近活动入口、页脚
- 三个主要栏目：社团介绍、最近活动、作品展示
- 作品展示分类页：卡片网格布局
- 最近活动分类页：活动时间线/列表
- 作品详情页：封面、标签、正文图片自动轮播、正文、下载/试玩锚点、相关作品
- 独立页面：宽版社团页面样式
- 移动端适配
- `settings.yaml` 后台主题配置项

## Halo 后台内容约定

建议在 Halo 后台创建分类：

| 显示名称 | 推荐 slug | 用途 | 首页/导航用途 |
| --- | --- | --- | --- |
| 作品展示 | `games` | 发布游戏作品、原型、Game Jam 成果 | 需要在主题设置中选为“作品展示分类” |
| 最近活动 | `activities` | 发布活动预告、活动回顾、分享会、比赛信息 | 需要在主题设置中选为“最近活动分类” |
| 社团公告 | `announcements` | 发布招新通知、站点公告、重要通知 | 普通文章分类 |
| 技术分享 | `tech-notes` | 发布引擎、工具链、开发复盘、教程 | 普通文章分类 |

建议创建独立页面：

| 页面标题 | 推荐 slug | 用途 | 首页/导航用途 |
| --- | --- | --- | --- |
| 社团介绍 | `about` | 介绍社团是谁、做什么、方向和理念 | 需要在主题设置中选为“社团介绍页面” |
| 加入我们 | `join` | 招新方式、加入要求、报名链接 | 需要在主题设置中选为“加入我们页面” |
| 联系我们 | `contact` | 合作、外联、社团负责人、邮箱、飞书/QQ群 | 面向合作联系，不承担内容上传 |

推荐标签：

- 引擎：`Unity`、`Godot`、`Unreal`、`WebGL`
- 类型：`2D`、`3D`、`像素风`、`塔防`、`解谜`、`动作`、`剧情`
- 场景：`Game Jam`、`课程项目`、`社团项目`、`练习作品`
- 分工：`程序`、`美术`、`策划`、`音乐`

安装主题后进入主题设置：

1. 在“导航页面”里选择社团介绍、加入我们、联系方式页面。
2. 在“首页内容”里选择作品展示分类和最近活动分类。
3. 在“首页轮播”里手动添加 3 到 6 张轮播图。
4. 设置 Hero 背景图、Logo、邮箱和社交链接。

注意：Halo 分类访问路径使用分类 slug，不使用中文分类名。不要手写 `/categories/作品展示` 这类地址；主题设置里选中分类后，主题会自动读取分类的真实 `permalink`。

图片上传支持：如果成员不会在 Halo 后台上传图片，请联系管理员 `support@zjutdev.games`，邮件里标注文章标题，并在附件里带上要上传的图片。主题默认兜底图也会显示这条提示。

## 让作品分类自动套用模板

在 Halo 后台只需要给分类设置一次模板，之后发布到该分类的文章会自动使用游戏详情样式：

1. 进入“文章”页面，点击右上角“分类”。
2. 新建或编辑“作品展示”分类。
3. 名称填 `作品展示`，别名推荐填 `games`。
4. “自定义模板”选择 `作品展示网格`。
5. “自定义文章模板”选择 `游戏作品详情`。
6. 保存分类。
7. 进入主题设置，在“首页内容”中把“作品展示分类”选择为这个分类。

“最近活动”分类同理，名称填 `最近活动`，别名推荐填 `activities`，不需要选择游戏详情文章模板。

用户发布作品时不需要填写“连接”。文章访问地址由文章设置里的“别名”自动生成，分类访问地址由分类设置里的“别名”自动生成。主题设置里的分类/页面选择器会读取 Halo 的真实链接。

如果要给成员一份正文格式参考，可以使用 [docs/game-post-template.md](docs/game-post-template.md) 里的内容作为文章正文模板。Halo 主题可以提供渲染模板，但不能仅靠主题把一段正文自动塞进后台编辑器；如果需要后台一键插入正文模板，需要额外编辑器插件支持。

## 游戏详情页可编辑字段

`游戏作品详情` 是前台渲染模板，不能在 Halo 后台直接修改模板 HTML。成员需要改的是“文章内容”和“文章设置里的元数据”。

主题已提供 `annotation-setting.yaml`，安装或重载主题配置后，文章设置底部会出现作品字段：

- 游戏引擎
- 游戏类型
- 运行平台
- 开发周期
- 团队名称
- 团队成员
- 简介
- 作品截图 1-6
- 下载链接
- 提取码
- 在线试玩链接
- GitHub 链接

这些字段会自动显示在游戏详情页的标题简介、基本信息下方的简介区、截图轮播和侧边按钮里。正文里仍然可以继续写介绍、玩法、开发记录等自由内容；`简介` 字段适合内容很短、只需要一段说明的作品。

图片使用建议：

- 文章封面图：使用 Halo 原生“封面图”，会显示在作品卡片和详情页顶部。
- 作品截图：使用文章设置里的“作品截图 1-6”，会优先生成详情页轮播。
- 正文图片：如果没有填写“作品截图 1-6”，详情页会退回读取正文里的图片生成轮播。

## 评论

评论区使用 Halo 官方评论扩展点 `<halo:comment>`。需要在 Halo 后台安装并启用“评论组件”插件，启用后文章详情页会自动显示评论框；未启用时会显示“评论组件未启用”的提示。

## 发布游戏作品

在 Halo 后台新建文章：

- 标题：游戏名称
- 分类：作品展示
- 标签：Unity / Godot / 2D / Game Jam 等
- 封面：游戏主视觉
- 摘要：一句话介绍
- 正文：介绍、截图、基本信息、下载链接、团队成员

推荐正文结构：

```markdown
## 介绍

这里写游戏简介。

## 基本信息

- 引擎：Unity
- 类型：平台跳跃
- 平台：Windows
- 团队：SOS工作室

## 下载

[Windows 下载](https://example.com)
提取码：xxxx

## 开源地址

[GitHub](https://github.com/xxx/xxx)
```

详情页的截图轮播会自动读取正文里的图片；如果正文没有图片，会使用文章封面。

## 发布最近活动

在 Halo 后台新建文章：

- 标题：活动名称
- 分类：最近活动
- 标签：Game Jam / 分享会 / 招新 / 比赛 等
- 封面：活动海报或现场照片
- 摘要：一句话说明活动内容
- 正文：时间、地点、报名方式、活动安排、回顾照片

### 活动文章示例

```markdown
---
标题：2026 夏季 Game Jam 招募
分类：最近活动
标签：Game Jam, 招新, 社团项目
摘要：48 小时主题创作，欢迎程序、美术、策划和音乐同学组队参加。
封面：上传活动海报
---

## 活动信息

- 时间：2026.06.21 - 2026.06.23
- 地点：屏峰校区 / 线上协作
- 面向对象：对游戏开发感兴趣的同学
- 报名方式：填写飞书表单或联系社团负责人

## 活动安排

1. 主题公布和组队
2. 快速原型开发
3. 中期试玩和反馈
4. 最终展示和复盘

## 需要准备

带上电脑，提前安装 Unity / Godot / Git。没有经验也可以参加，会安排基础引导。
```

## 打包安装

确认目录名为 `halo-theme-zjutdev` 后，将整个目录压缩为 zip，在 Halo 后台的主题管理中上传并启用。

## 维护说明

本主题没有独立 CMS、独立登录页、独立上传页、复杂筛选系统或自定义内容模型插件。第一版优先用 Halo 原生文章、分类、标签、独立页面和附件能力完成长期可维护的网站。
